# PUMP.FUN Bruxo Bode

Sistema web multiusuário de cópia de traders da pump.fun (login com Google, dados no Supabase).
Criado a partir da aba PUMP.FUN do `hermes-jev-trader` — veja `docs/ORIGEM.md`.

> Em construção. O passo a passo de instalação completo entra na etapa de Docker/Caddy.

Testes (rodam sem internet): `pip install -r requirements.txt pytest && pytest -q`
